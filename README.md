# Hackatón Tren Solar

Plataforma de inteligencia territorial para la prevención del delito en Jujuy:
mapa de calor de incidentes agregados, panel de tendencias y recomendaciones
de prevención situacional.

- `frontend/` — React + Vite + TypeScript
- `backend/` — NestJS + Prisma + MySQL 8
- `docs/` — documentación del proyecto

Ver [AGENTS.md](AGENTS.md) y [CONTRIBUTING.md](CONTRIBUTING.md).
